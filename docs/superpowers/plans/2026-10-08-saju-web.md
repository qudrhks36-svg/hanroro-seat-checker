# 사주 웹서비스 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 생년월일시로 사주 4주·오행·십성·신강/신약·올해 세운 풀이와 궁합 상대 추천·상대 사주 입력 궁합을 보여주고, 결과를 PNG 카드로 저장·공유하는 무료 정적 웹사이트.

**Architecture:** 서버 없는 Vite + React SPA. 계산은 검증된 만세력 라이브러리(`lunar-typescript`)가 담당하고, 그 위의 오행/십성/신강·용신/궁합은 작은 순수 함수(`src/lib`)로 구현한다. 해석 문구는 `src/data/readings.json`에서 조합한다. UI는 shadcn/ui.

**Tech Stack:** Vite, React 19, TypeScript, Tailwind v4, shadcn/ui, `lunar-typescript`, `html-to-image`, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-08-saju-web-design.md`

## Global Constraints

- 위치: 저장소 루트의 `saju_web/`. 명령은 별도 표기가 없으면 `saju_web/`에서 실행.
- 서버·DB·API 키 없음. 입력값은 브라우저 밖으로 전송하지 않는다.
- 지원 연도 1900~2100. 범위 밖이면 입력 단계에서 한국어 사유와 함께 막는다.
- 연주·월주는 한국 시각에서 1시간을 뺀 값으로 계산한다 (라이브러리 절기가 UTC+8 기준). 일주·시주는 한국 시각 그대로, 자시는 야자시(23시 이후도 당일 일주 유지).
- UI 문구는 모두 한국어. 문체는 전문가 톤(명리 용어 + 괄호 쉬운 설명). "재미/오락용" 같은 면책 문구는 쓰지 않는다. 흉운·질병 단정, 의료·투자 판단 표현 금지.
- 같은 입력은 항상 같은 결과 (난수·현재시각 의존은 `currentYear` 인자로만).
- `src/lib/*`는 `@/` 별칭 대신 상대 경로 import (Vitest 단순화).
- 커밋은 `git add` 로 `saju_web`과 `docs/superpowers` 경로만 추가한다. 커밋 메시지 끝에 `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

```ts
// 인덱스 = 일간 오행에서 상대 오행까지의 거리 (0 같은 오행, 1 내가 생함, 2 내가 극함, 3 나를 극함, 4 나를 생함)

const GOD_BY_GROUP: Record<TenGodGroup, [TenGod, TenGod]> = {
  // [음양 같음, 음양 다름]
  비겁: ['비견', '겁재'],
  식상: ['식신', '상관'],
  재성: ['편재', '정재'],
  관성: ['편관', '정관'],
  인성: ['편인', '정인'],
}

export const ganEl = (gan: string): Element => GAN_ELEMENT[GAN.indexOf(gan)]
export const zhiEl = (zhi: string): Element => ZHI_ELEMENT[ZHI.indexOf(zhi)]
export const isYang = (gan: string): boolean => GAN.indexOf(gan) % 2 === 0

export function groupBetween(dayGan: string, other: string): TenGodGroup {
  const d = (ELEMENTS.indexOf(ganEl(other)) - ELEMENTS.indexOf(ganEl(dayGan)) + 5) % 5
  return GROUPS[d]
}

export function tenGod(dayGan: string, other: string): TenGod {
  const same = isYang(dayGan) === isYang(other)
  return GOD_BY_GROUP[groupBetween(dayGan, other)][same ? 0 : 1]
}

export const groupElement = (dayEl: Element, g: TenGodGroup): Element =>
  ELEMENTS[(ELEMENTS.indexOf(dayEl) + GROUPS.indexOf(g)) % 5]

const LIUHE = ['子丑', '寅亥', '卯戌', '辰酉', '巳申', '午未']
const SANHE = ['申子辰', '亥卯未', '寅午戌', '巳酉丑']
const CHONG = ['子午', '丑未', '寅申', '卯酉', '辰戌', '巳亥']
const GAN_HE = ['甲己', '乙庚', '丙辛', '丁壬', '戊癸']
const has = (list: string[], a: string, b: string) => list.some((s) => s.includes(a) && s.includes(b))

export type ZhiRel = '육합' | '삼합' | '충' | null
export function zhiRelation(a: string, b: string): ZhiRel {
  if (a === b) return null
  if (has(LIUHE, a, b)) return '육합'
  if (has(CHONG, a, b)) return '충'
  if (has(SANHE, a, b)) return '삼합'
  return null
}

export const ganHe = (a: string, b: string): boolean => a !== b && has(GAN_HE, a, b)
```

```ts
import { Solar, Lunar, LunarYear } from 'lunar-typescript'

export type Gender = 'male' | 'female'
export type BirthInput = {
  calendar: 'solar' | 'lunar'
  year: number
  month: number
  day: number
  leap?: boolean
  hour?: number
  minute?: number
  gender: Gender
}
export type Pillar = { gan: string; zhi: string }
export type Pillars = { year: Pillar; month: Pillar; day: Pillar; time: Pillar | null }
export type SolarDate = { y: number; m: number; d: number }

export const MIN_YEAR = 1900
export const MAX_YEAR = 2100
export class BirthInputError extends Error {}

function fail(msg: string): never {
  throw new BirthInputError(msg)
}

export function toSolar(i: BirthInput): SolarDate {
  const { year, month, day } = i
  if (![year, month, day].every(Number.isInteger)) fail('생년월일을 숫자로 입력해 주세요.')
  if (year < MIN_YEAR || year > MAX_YEAR) fail(`${MIN_YEAR}~${MAX_YEAR}년 사이만 지원합니다.`)
  if (i.calendar === 'solar') {
    const t = new Date(Date.UTC(year, month - 1, day))
    if (t.getUTCFullYear() !== year || t.getUTCMonth() !== month - 1 || t.getUTCDate() !== day)
      fail('존재하지 않는 양력 날짜입니다.')
    return { y: year, m: month, d: day }
  }
  if (month < 1 || month > 12) fail('음력 월은 1~12 사이여야 합니다.')
  const ly = LunarYear.fromYear(year)
  if (i.leap && ly.getLeapMonth() !== month) fail(`${year}년에는 윤${month}월이 없습니다.`)
  const signed = i.leap ? -month : month
  const lm = ly.getMonth(signed)
  if (!lm || day < 1 || day > lm.getDayCount()) fail('존재하지 않는 음력 날짜입니다.')
  const s = Lunar.fromYmd(year, signed, day).getSolar()
  return { y: s.getYear(), m: s.getMonth(), d: s.getDay() }
}

function readTime(i: BirthInput): { hour: number; minute: number } | null {
  const { hour: h, minute: m } = i
  if (h === undefined && m === undefined) return null
  if (h === undefined || m === undefined || !Number.isInteger(h) || !Number.isInteger(m) || h < 0 || h > 23 || m < 0 || m > 59)
    fail('태어난 시간을 올바르게 입력해 주세요.')
  return { hour: h, minute: m }
}

const split = (gz: string): Pillar => ({ gan: gz[0], zhi: gz[1] })

export function calcPillars(i: BirthInput): { solar: SolarDate; pillars: Pillars } {
  const solar = toSolar(i)
  const time = readTime(i)
  // ponytail: 시간 모름이면 정오 기준으로 연·월·일 계산. 절기 당일 출생이면 월주가 달라질 수 있음.
  const h = time?.hour ?? 12
  const mi = time?.minute ?? 0
  // 일주·시주: 한국 시각 그대로. sect 2 = 야자시(23시 이후도 당일 일주 유지).
  const kst = Solar.fromYmdHms(solar.y, solar.m, solar.d, h, mi, 0).getLunar().getEightChar()
  kst.setSect(2)
  // 연주·월주: 라이브러리 절기가 UTC+8 기준이라 한국 시각에서 1시간을 뺀다.
  const t = new Date(Date.UTC(solar.y, solar.m - 1, solar.d, h - 1, mi))
  const cst = Solar.fromYmdHms(
    t.getUTCFullYear(), t.getUTCMonth() + 1, t.getUTCDate(), t.getUTCHours(), t.getUTCMinutes(), 0,
  ).getLunar().getEightChar()
  return {
    solar,
    pillars: {
      year: split(cst.getYear()),
      month: split(cst.getMonth()),
      day: split(kst.getDay()),
      time: time ? split(kst.getTime()) : null,
    },
  }
}
```

`saju_web/src/lib/analysis.ts`:
```ts
import type { Pillar, Pillars } from './saju'
import {
  ELEMENTS, GROUPS, ZHI, ZHI_MAIN_GAN, ganEl, zhiEl, groupBetween, groupElement,
  type Element, type TenGodGroup,
} from './tables'

export type Strength = '신강' | '중화' | '신약'
export type Analysis = {
  dayGan: string
  dayElement: Element
  elements: Record<Element, number>
  lacking: Element[]
  groups: Record<TenGodGroup, number>
  dominantGroup: TenGodGroup
  ratio: number
  strength: Strength
  yongshin: Element
}

export function analyze(p: Pillars): Analysis {
  const dayGan = p.day.gan
  const dayElement = ganEl(dayGan)
  const elements: Record<Element, number> = { 木: 0, 火: 0, 土: 0, 金: 0, 水: 0 }
  const groups: Record<TenGodGroup, number> = { 비겁: 0, 식상: 0, 재성: 0, 관성: 0, 인성: 0 }

  const count = (pl: Pillar) => {
    elements[ganEl(pl.gan)]++
    elements[zhiEl(pl.zhi)]++
  }
  const addZhi = (zhi: string, w: number) => {
    groups[groupBetween(dayGan, ZHI_MAIN_GAN[ZHI.indexOf(zhi)])] += w
  }
  for (const [pos, pl] of [['year', p.year], ['month', p.month], ['time', p.time]] as const) {
    if (!pl) continue
    count(pl)
    groups[groupBetween(dayGan, pl.gan)] += 1
    addZhi(pl.zhi, pos === 'month' ? 3 : 1) // 월지(득령)만 가중치 3
  }
  count(p.day) // 일간은 기준이라 십성에서 제외, 일지만 반영
  addZhi(p.day.zhi, 1)

  const total = GROUPS.reduce((s, g) => s + groups[g], 0)
  const ratio = (groups.비겁 + groups.인성) / total
  // ponytail: 단순 비율 임계값(0.55/0.40). 조후·통관·지장간 가중치는 미반영, 정밀화가 필요하면 여기부터 교체.
  const strength: Strength = ratio >= 0.55 ? '신강' : ratio <= 0.4 ? '신약' : '중화'
  const dominantGroup = GROUPS.reduce((best, g) => (groups[g] > groups[best] ? g : best))

  const cand: TenGodGroup[] =
    strength === '신강' ? ['식상', '재성', '관성'] : strength === '신약' ? ['인성', '비겁'] : GROUPS
  const yongshin = cand
    .map((g) => groupElement(dayElement, g))
    .reduce((best, e) => (elements[e] < elements[best] ? e : best))

  return {
    dayGan, dayElement, elements,
    lacking: ELEMENTS.filter((e) => elements[e] === 0),
    groups, dominantGroup, ratio, strength, yongshin,
  }
}
```

```ts
import { Solar } from 'lunar-typescript'
import raw from '../data/readings.json'
import type { Pillars } from './saju'
import type { Analysis } from './analysis'
import {
  ELEMENT_KO, ganEl, zhiEl, groupBetween, groupElement, tenGod, GAN, GAN_KO,
  type Element, type TenGod, type TenGodGroup,
} from './tables'

type Pair = { trait: string; work: string }
const D = raw as unknown as {
  dayGan: Record<string, string>
  dayZhi: Record<string, string>
  group: Record<TenGodGroup, Pair>
  lacking: Record<Element, string>
  balanced: string
  strength: Record<string, { summary: string; advice: string }>
  yongshin: Record<Element, string>
  sewoon: Record<TenGodGroup, string>
  sewoonMatch: { yes: string; no: string }
  partnerType: Record<Element, string>
  spouseStar: { male: string; female: string }
}
export const readings = D

export type Section = { title: string; body: string[] }

export const elementLabel = (e: Element) => `${ELEMENT_KO[e]}(${e})`

export function dayGanName(gan: string): string {
  const i = GAN.indexOf(gan)
  return `${GAN_KO[i]}${ELEMENT_KO[ganEl(gan)]}(${gan}${ganEl(gan)})`
}

export const headline = (a: Analysis) =>
  `${dayGanName(a.dayGan)} 일간 · ${a.strength} · 용신 ${elementLabel(a.yongshin)}`

export function interpret(p: Pillars, a: Analysis): Section[] {
  const s = D.strength[a.strength]
  const g = D.group[a.dominantGroup]
  return [
    { title: '기본 성향', body: [D.dayGan[a.dayGan], D.dayZhi[p.day.zhi]] },
    { title: '사주 구조', body: [s.summary, g.trait] },
    { title: '오행 균형', body: a.lacking.length ? a.lacking.map((e) => D.lacking[e]) : [D.balanced] },
    { title: '직업·활동 경향', body: [g.work] },
    { title: '조언', body: [s.advice, D.yongshin[a.yongshin]] },
  ]
}

export type YearFortune = {
  year: number
  ganzhi: string
  god: TenGod
  group: TenGodGroup
  matchesYongshin: boolean
  body: string[]
}

export function yearFortune(a: Analysis, year: number): YearFortune {
  const ganzhi = Solar.fromYmd(year, 6, 1).getLunar().getYearInGanZhi() // 6월 1일은 항상 입춘 이후
  const [gan, zhi] = [ganzhi[0], ganzhi[1]]
  const god = tenGod(a.dayGan, gan)
  const group = groupBetween(a.dayGan, gan)
  const matchesYongshin = ganEl(gan) === a.yongshin || zhiEl(zhi) === a.yongshin
  const match = (matchesYongshin ? D.sewoonMatch.yes : D.sewoonMatch.no).replace('{el}', elementLabel(a.yongshin))
  return {
    year, ganzhi, god, group, matchesYongshin,
    body: [`${year}년(${ganzhi})의 천간은 일간 기준 ${god}에 해당하며, ${D.sewoon[group]}`, match],
  }
}

/** 배우자성(남 재성 / 여 관성) 오행 문장 — compat.ts 에서 사용 */
export function spouseStarText(a: Analysis, gender: 'male' | 'female'): string {
  const el = groupElement(a.dayElement, gender === 'male' ? '재성' : '관성')
  return D.spouseStar[gender].replace('{el}', elementLabel(el))
}
```

```ts
import { Solar } from 'lunar-typescript'
import type { Pillars, Gender } from './saju'
import { MIN_YEAR, MAX_YEAR } from './saju'
import type { Analysis } from './analysis'
import { ZHI, ZODIAC, ganEl, zhiEl, ganHe, zhiRelation, type ZhiRel } from './tables'
import { readings, spouseStarText } from './interpret'

export type PartnerRec = {
  zodiac: { good: string[]; caution: string[] }
  type: string
  ages: { year: number; ganzhi: string; label: string; reason: string }[]
}

const zodiacOf = (zhi: string) => ZODIAC[ZHI.indexOf(zhi)]
const related = (base: string, rel: ZhiRel) => ZHI.filter((z) => zhiRelation(base, z) === rel)

export function recommendPartners(
  p: Pillars,
  a: Analysis,
  o: { gender: Gender; birthYear: number; currentYear: number },
): PartnerRec {
  const bases = [p.year.zhi, p.day.zhi]
  const good = [...new Set(bases.flatMap((b) => [...related(b, '육합'), ...related(b, '삼합')]))]
  const caution = [...new Set(bases.flatMap((b) => related(b, '충')))].filter((z) => !good.includes(z))

  const cands: { year: number; ganzhi: string; score: number; reasons: string[] }[] = []
  const last = Math.min(o.birthYear + 10, MAX_YEAR, o.currentYear - 19) // ponytail: 만 19세 이상만 추천
  for (let y = Math.max(o.birthYear - 10, MIN_YEAR); y <= last; y++) {
    const ganzhi = Solar.fromYmd(y, 6, 1).getLunar().getYearInGanZhi()
    let score = 0
    const reasons: string[] = []
    for (const [name, base] of [['띠', p.year.zhi], ['일지', p.day.zhi]] as const) {
      const rel = zhiRelation(base, ganzhi[1])
      if (rel === '육합') { score += 3; reasons.push(`${name} 육합`) }
      else if (rel === '삼합') { score += 2; reasons.push(`${name} 삼합`) }
      else if (rel === '충') { score -= 3 }
    }
    if (zhiEl(ganzhi[1]) === a.yongshin) { score += 2; reasons.push('지지가 용신 오행') }
    if (ganEl(ganzhi[0]) === a.yongshin) { score += 1; reasons.push('천간이 용신 오행') }
    if (score > 0) cands.push({ year: y, ganzhi, score, reasons })
  }
  const gap = (y: number) => y - o.birthYear
  cands.sort((x, y) => y.score - x.score || Math.abs(gap(x.year)) - Math.abs(gap(y.year)) || gap(x.year) - gap(y.year))

  return {
    zodiac: { good: good.map(zodiacOf), caution: caution.map(zodiacOf) },
    type: `${readings.partnerType[a.yongshin]} ${spouseStarText(a, o.gender)}`,
    ages: cands.slice(0, 3).map((c) => {
      const g = gap(c.year)
      const label = g === 0 ? '동갑' : g > 0 ? `${g}살 연하` : `${-g}살 연상`
      return { year: c.year, ganzhi: c.ganzhi, label, reason: c.reasons.join(', ') }
    }),
  }
}

export type Compat = { score: number; level: string; reasons: string[]; cautions: string[] }

const LEVELS: [number, string][] = [[80, '매우 좋음'], [65, '좋음'], [50, '무난함'], [35, '조율 필요']]

export function compatibility(p1: Pillars, a1: Analysis, p2: Pillars, a2: Analysis): Compat {
  let score = 40
  const reasons: string[] = []
  const cautions: string[] = []

  const dayRel = zhiRelation(p1.day.zhi, p2.day.zhi)
  if (dayRel === '육합') { score += 20; reasons.push('일지(배우자궁) 육합: 서로를 끌어당기는 안정적인 결합입니다.') }
  else if (dayRel === '삼합') { score += 12; reasons.push('일지(배우자궁) 삼합: 함께할수록 힘이 커지는 조합입니다.') }
  else if (dayRel === '충') { score -= 20; cautions.push('일지(배우자궁) 충: 생활 방식과 기준 차이를 의식적으로 조율해야 합니다.') }

  const yearRel = zhiRelation(p1.year.zhi, p2.year.zhi)
  if (yearRel === '육합' || yearRel === '삼합') { score += 8; reasons.push(`띠 ${yearRel}: 기본 기질이 잘 어울립니다.`) }
  else if (yearRel === '충') { score -= 8; cautions.push('띠 충: 기질이 부딪히기 쉬워 대화로 완충이 필요합니다.') }

  if (ganHe(p1.day.gan, p2.day.gan)) { score += 15; reasons.push('일간 천간합: 서로의 본질이 자연스럽게 맞물립니다.') }

  const fill = (from: Analysis, to: Analysis, who: string) => {
    const n = to.elements[from.yongshin]
    if (n >= 2) { score += 10; reasons.push(`${who}의 용신 오행(${from.yongshin})을 상대 사주가 풍부하게 채워 줍니다.`) }

  }
  fill(a1, a2, '나')
  fill(a2, a1, '상대')

  score = Math.max(0, Math.min(100, score))
  return { score, level: LEVELS.find(([min]) => score >= min)?.[1] ?? '신중한 조율 필요', reasons, cautions }
```

```ts
import { toPng } from 'html-to-image'

const render = (node: HTMLElement) => toPng(node, { pixelRatio: 2, cacheBust: true })

export async function savePng(node: HTMLElement): Promise<void> {
  const a = document.createElement('a')
  a.href = await render(node)
  a.download = 'saju.png'
  a.click()
}

/** Web Share API(파일 공유)가 되면 공유, 아니면 저장으로 대체 */
export async function sharePng(node: HTMLElement): Promise<void> {
  const blob = await (await fetch(await render(node))).blob()
  const file = new File([blob], 'saju.png', { type: 'image/png' })
  if (navigator.canShare?.({ files: [file] })) await navigator.share({ files: [file], title: '내 사주 결과' })
  else await savePng(node)
}
```

- [ ] **Step 2: CompatPanel**

`saju_web/src/components/CompatPanel.tsx`:
```tsx
import { useState } from 'react'
import { Badge } from '@/components/ui/badge'
import { Card, CardContent, CardHeader, CardTitle, CardDescription } from '@/components/ui/card'
import { Progress } from '@/components/ui/progress'
import { InputForm } from '@/components/InputForm'
import { compatibility, type Compat } from '@/lib/compat'
import { buildPerson } from '@/lib/person'
import { BirthInputError, type BirthInput } from '@/lib/saju'
import type { Person } from '@/lib/person'

export function CompatPanel({ me }: { me: Person }) {
  const [result, setResult] = useState<Compat | null>(null)
  const [error, setError] = useState('')

  const submit = (b: BirthInput) => {
    try {
      const other = buildPerson(b)
      setResult(compatibility(me.pillars, me.analysis, other.pillars, other.analysis))
      setError('')
    } catch (e) {
      setResult(null)
      setError(e instanceof BirthInputError ? e.message : '계산 중 오류가 발생했습니다. 입력값을 확인해 주세요.')
    }
  }

  return (
    <Card>
      <CardHeader className="pb-2">
        <CardTitle className="text-base">상대 사주로 궁합 보기</CardTitle>
        <CardDescription>상대의 생년월일시를 입력하면 일지·띠의 합충, 일간 합, 용신 보완도를 종합합니다.</CardDescription>
      </CardHeader>
      <CardContent className="space-y-5">
        <InputForm submitLabel="궁합 보기" onSubmit={submit} error={error} />
        {result && (
          <div className="space-y-3 border-t pt-4 text-sm leading-relaxed">
            <div className="flex items-center gap-3">
              <span className="text-3xl font-semibold tabular-nums">{result.score}</span>
              <Badge>{result.level}</Badge>
            </div>
            <Progress value={result.score} className="h-2" />
            {result.reasons.map((t, i) => <p key={`r${i}`}>{t}</p>)}
            {result.cautions.map((t, i) => <p key={`c${i}`} className="text-muted-foreground">주의: {t}</p>)}
          </div>
        )}
      </CardContent>
    </Card>
  )
}
```
