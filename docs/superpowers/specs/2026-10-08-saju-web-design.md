# 사주 웹서비스 설계 (1차)

## 목표
생년월일시를 입력하면 사주 4주·오행·십성·신강/신약, 올해 세운 풀이를 보여주고 결과를 이미지 카드로 저장·공유하는 무료 정적 웹사이트. 서버 없음, 입력값은 브라우저 밖으로 나가지 않는다.

## 스택
- Vite + React + TypeScript, Tailwind, **shadcn/ui** (Card, Form, Select, Tabs, Button, Progress 등)
- 배포: Vercel 정적 호스팅 (서버·DB·API 키 없음)
- 위치: `saju_web/`

## 구조
```
saju_web/
  src/lib/saju.ts        # 계산 어댑터: 만세력 라이브러리 호출 → SajuResult(JSON) 반환
  src/lib/interpret.ts   # SajuResult + 해석 데이터 → 풀이 섹션 배열 (순수 함수)
  src/data/*.json        # 일간·일주(60갑자)·십성·오행부족·신강신약·세운 풀이 문구
  src/components/        # InputForm, PillarsTable, ElementChart, ReadingSections, YearFortune, ShareCard
  src/App.tsx            # 입력 → 결과 단일 페이지
  tests/saju.test.ts     # 정확도 검증
```
- 계산 라이브러리는 직접 구현하지 않고 검증된 npm 패키지를 쓴다. 후보 `saju-fortune`을 먼저 브라우저 번들 가능 여부·정확도로 검증하고, 안 되면 `lunar-javascript` 등으로 교체한다.
- `SajuResult` JSON 형식을 처음에 고정한다. 이후 AI 풀이를 붙일 때 이 JSON을 그대로 넘기면 된다 (1차에서는 AI 연결 안 함).

## 입력
양력/음력(윤달 체크), 생년월일, 태어난 시간(모름 허용), 성별. 시간 모름이면 시주 없이 연·월·일 기준으로 풀이하고 화면에 표기한다. 이름·출생지는 받지 않는다.

## 기능 (1차)
1. **조합형 풀이**: 일간·일주·월지·십성 분포·오행 과부족·신강/신약·용신 방향을 조합해 섹션별 풀이(성향 / 강점 / 보완점 / 직업·관계 경향 / 조언)를 생성. 문구는 JSON 데이터에서 조합하며 같은 입력은 항상 같은 결과.
2. **올해 세운**: 올해 간지와 사주의 십성 관계, 용신 부합 여부로 올해 흐름 요약.
3. **결과 카드 이미지 저장·공유**: 사주표 + 오행 + 핵심 한 줄 요약을 카드로 렌더링해 PNG 저장 (html-to-image). 모바일은 Web Share API 지원 시 공유.

4. **궁합 상대 추천**: 내 사주만으로 잘 맞는 띠(육합·삼합 / 충 주의), 상대 유형(용신 오행 기질), 나이차(출생연도 후보 상위 3개)를 추천. 규칙 기반 점수, 같은 입력은 항상 같은 결과.
5. **상대 사주 입력 궁합**: 상대의 생년월일시를 입력하면 일지·연지의 합/충, 일간 천간합, 서로의 용신 오행 보완도를 합산해 0~100 점수와 근거 문장을 제시. 상대 입력 폼은 내 입력 폼을 재사용.

## 문체 원칙
- 전문가 톤: 명리 용어(일간, 십성, 신강/신약, 용신)를 쓰고, 괄호로 쉬운 설명을 병기.
- "재미/오락용" 같은 면책 문구는 넣지 않는다.
- 단정적 흉운·사망·질병 확정, 의료·투자 판단 표현은 쓰지 않는다. 경향과 조언 중심으로 서술.

## 에러 처리
유효하지 않은 날짜(윤달 불일치, 범위 밖 연도)는 입력 단계에서 막고 사유 표시. 계산 라이브러리 지원 연도 범위 밖이면 안내.

## 테스트
`tests/saju.test.ts` 한 파일: 알려진 사주 사례 대조 (입춘 전후 생일 2건, 자시 경계 1건, 음력 윤달 1건, 시간 모름 1건). `interpret`는 같은 입력 → 같은 출력과 필수 섹션 존재 여부만 확인.

## 1차 제외
월별 운세, 회원·결제, AI 풀이, 이름·출생지 경도 보정, 3인 이상 궁합.
