## 사용자 후기에서 나온 개선 요청

1. MBTI와 사주의 공통점을 **벤다이어그램처럼 시각화**해 직관적으로 보이게.
2. 텍스트가 너무 **줄글 형식**이라는 지적.
3. "사주아이"라는 앱과 비슷하고 **지루하다**는 의견. (사주아이가 어떤 앱인지는 웹 검색에서 정보를 못 찾음. 어떤 점이 비슷하다고 했는지 사용자에게 확인 필요)

사용자 스케치(손그림): 두 개의 원이 겹친 벤다이어그램. 왼쪽 "사주", 오른쪽 "ESFJ", 가운데 겹침 = 공통점. 원 안 손글씨는 판독 불가였음.

## 사용자가 정한 것

- 개선 범위는 "세 가지 모두": (1) MBTI 관련 시각화, (2) 줄글→카드형, (3) 재미 요소(캐릭터 + 공유 카드 개편).
- 추가 요청 (이번 대화):
  - **사주를 바탕으로 캐릭터를 만들어 주기** ("자신을 닮은 캐릭터").
  - **MBTI를 입력하지 않고** 사주에서 MBTI를 **예측**: E/I, S/N, T/F, J/P 4축 모두 비율로 보여주기. 예: "T 40% / F 60%일 확률이 높아요". F인 사람에게 T 40%가 어떻게 작용하는지를 사주 근거로 설명하고, "사주가 이러니까 이렇게 살면 좋다"는 조언을 붙이는 느낌.
- 해석은 규칙 기반(서버·AI 비용 없음) 유지. 유료 API(AI 이미지 생성 등)를 쓰기 전에는 먼저 물어보기 (CLAUDE.md 규칙).

## 제안한 구성 (사용자 승인 전)

| 화면 | 내용 |
|---|---|
| 결과 맨 위 | 사주 기반 캐릭터와 닉네임, 한 줄 요약, 키워드 칩 |
| MBTI 4축 | 막대 그래프(15~85%로 제한), 축별 "근거 보기", 축별 한 줄 조언 |
| 비교 (선택) | 내 MBTI를 입력하면 벤다이어그램: 왼쪽 "사주가 말하는 나", 오른쪽 "내 MBTI", 가운데 일치하는 축·키워드 |
| 풀이 섹션 | 줄글을 요약 한 줄, 키워드 칩, 불릿 3줄, 세기 막대로 바꾸고 긴 설명은 "더 보기"로 접음 |

### 핵심 설계 판단

- **벤다이어그램 역할 변경 제안**: 사주에서 MBTI를 예측하면 "사주 ∩ 예측 MBTI" 벤다이어그램은 같은 정보를 두 번 보여주는 순환이 됨. 그래서 기본 화면은 4축 막대, 벤다이어그램은 **실제 MBTI를 선택 입력했을 때만** 사주 예측과 비교하는 용도로 쓰자고 제안함. (사용자 확인 대기)
- **MBTI 예측 계산 방식(초안)**: 일간 오행, 오행 분포, 십성 5그룹, 신강/신약에 축별 가중치를 주어 점수 → 15~85%로 제한. 같은 입력은 항상 같은 결과. 축마다 근거(예: "화 기운이 많아 E 쪽 +20")를 표시.
- **정직성**: 사주와 MBTI를 잇는 검증된 대응표는 없음. 가중치는 우리가 정한 해석 규칙이므로 "사주 기운을 MBTI 축으로 번역한 경향"으로 표기하고 근거를 열어 보게 함. 실제 MBTI와 안 맞는 사람이 반드시 나오므로, 선택 입력 비교 기능으로 이탈을 줄이는 것이 목적.
- **캐릭터 생성(초안)**: 일간(10) = 기본 캐릭터, 일지(12) = 소품·분위기, 신강/신약 = 표정·자세, 닉네임 자동 생성(예: "다정한 정원사"). 그림 방식은 미정: 이모지+색 조합(무료·즉시) → 레이어 일러스트 → AI 이미지 생성(유료, 사전 확인 필요) 순으로 교체 가능하게 설계.
- **미룰 것**: 친구 초대, 두 사람 벤다이어그램 비교, 일일 운세 재방문 유도.

## 열린 질문 (다음에 이어서 정할 것)

1. 벤다이어그램을 "선택 입력으로 내 MBTI와 비교"하는 쪽으로 바꾸는 것에 동의하는지.
2. 캐릭터 그림 방식: 이모지+색 조합으로 시작해도 되는지, AI 이미지 생성(유료)을 쓸 건지.
3. 사주아이와 구체적으로 어떤 점이 비슷하다고 했는지 (화면 구성, 풀이 문구, 결과 카드 등). 차별점이 그 부분을 해결하는지 검토하기 위함.
4. (선택) 저장소 분리: 현재 PUBLIC인 `hanroro-seat-checker`에 사주 코드가 같이 있는 것이 괜찮은지.

## v1에서 아직 확인 못 한 것 (v2 작업 때 같이 볼 것)

- 본인 생일로 4주를 외부 만세력과 비교 (입춘 경계, 윤달, 자시).
- PNG 저장·공유의 실제 모습: 한글 글꼴 표시, 실제 파일 다운로드, 공유 시트. 내장 브라우저에서는 화면 캡처가 안 돼서 확인 못 함.
- 과거 한국 표준시(UTC+8:30, 1954~61년)와 서머타임(1948~51, 1955~60, 1987~88년)은 계산에 반영하지 않음.
- 신강/신약 기준(0.55/0.40)이 느슨해 경계 사례가 "중화"로 나옴.
