# 낚시 섬 (Fishing Island)

한적한 섬에서 느긋하게 낚시하는 1인칭 힐링 게임. 브라우저(PC)에서 바로 플레이해요.

## 할 수 있는 것
- 낚시: 낮·노을·밤, 맑음·흐림·비마다 달라지는 섬에서 미끼를 골라 물고기를 낚아요. 16종 도감(크기 기록 포함).
- 먼 바다: 부두의 배를 타고 먼 바다에서만 잡히는 물고기를 낚아요.
- 살림: 바틀이에게 팔고, 낚싯대를 키우고, 오두막과 장식을 꾸며요.
- 소소한 재미: 오늘의 목표, 떠내려온 병 속 쪽지, 갈매기, 사진 찍기(P).

## 조작
`클릭` 시작 · `WASD` 이동 · `마우스` 시점 · `왼쪽 클릭` 낚시 · `1·2·3` 미끼 · `E` 말 걸기/줍기/배 · `Tab` 도감 · `P` 사진 · `M` 소리 · `Esc` 마우스 풀기

## 만든 방법
- 유니티 6.3 LTS(URP, Input System) · 블렌더 5.2(로우폴리 모델·그림) · WebGL 빌드를 Vercel에 배포.
- 기획서 `docs/GDD.md`가 기준이고, 바뀐 내용은 `changelog/`, 검수 기록은 `review/`에 있어요.
- 블렌더 스크립트: `blender/` (`make_*.py`), 유니티 에디터 도구: `fish game/Assets/Editor/`.
