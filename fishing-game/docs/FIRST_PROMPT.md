# 로컬 클로드 코드 첫 작업 지시문

`fishing-game/` 폴더에서 클로드 코드를 실행하고, 유니티·블렌더 MCP 연결을 확인한 뒤 아래 내용을 그대로 붙여 넣어요.

---

CLAUDE.md와 docs/GDD.md, docs/reference/notes.md를 먼저 읽어 줘.
GDD에 없는 내용은 짐작하지 말고 질문해 줘.

**이번 작업: 10번 만들 순서의 1단계 (임시 도형으로 섬 맵 구성)**

유니티 MCP로 아래를 만들어 줘.
- 작은 섬 하나 (납작한 원기둥이나 평면), 주변은 바다 평면
- 부두 (긴 직육면체), 오두막 (큐브 + 지붕 삼각형), 야자수 몇 그루 (원기둥 + 구), 배 (직육면체) 자리
- 이름을 알아보기 쉽게 붙이고 `Island` 오브젝트 아래에 정리
- 색은 노을빛 분위기를 참고하되 단색 머티리얼만 사용
- 모델링과 텍스처는 하지 말고, 나중에 블렌더 모델로 바꿀 수 있게 위치와 크기만 잡아 줘

**진행 규칙**
1. 만들기 전에 계획을 먼저 짧게 보여 주고, 내가 OK하면 시작해 줘.
2. 다 만들면 검수용 서브에이전트(만든 에이전트와 다른 에이전트)가 GDD 8번 맵 항목과 비교해서 통과/반려만 `review/`에 기록해 줘.
3. 고친 내용과 이유는 `changelog/`에 날짜별로 남겨 줘.
4. 끝나면 내가 직접 플레이(씬 확인)할 수 있게 방법을 알려 주고, 내 피드백을 기다려 줘. 다음 단계(걷기)는 내가 말하기 전에는 시작하지 마.
