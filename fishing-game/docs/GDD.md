# 낚시 게임 기획서 (GDD) v0.2

> 이 문서가 모든 작업의 기준이에요. 문서에 없는 내용은 짐작해서 만들지 않고 먼저 질문해요.
> `[확정]`은 사용자가 정한 것이에요. 새로 제안한 내용은 `[제안]`으로 표시하고, 확인받으면 `[확정]`으로 바꿔요.

## 1. 한 줄 소개
[확정] 잔잔하고 귀여운 작은 섬에서, 1인칭으로 낚시하며 도감을 채우고 장비를 키우는 힐링 낚시 게임.

## 2. 분위기
- [확정] 잔잔한 힐링 + 아기자기하고 귀여운 느낌
- [확정] 따뜻한 노을빛, 밝고 동글동글한 로우폴리 그림체, 부드러운 파도·바람 소리
- 참고 이미지 [확정]: `docs/reference/` 참고. 분위기·맵은 mood_map_* 2장, 도감·UI는 ui_* 3장. 이미지별 메모는 `docs/reference/notes.md`.

## 3. 세계관
- [확정] 한적한 바다 위의 작은 섬. 플레이어는 낡은 낚시 오두막을 물려받아 지내요.
- [확정] 대사는 많지 않게, 동물의 숲 같은 느긋하고 따뜻한 말투로 가끔 등장해요.
- [확정] 대사는 짧은 말풍선/대화창 형식. 낚시 팁, 물고기 구매 같은 일상 대화 위주.
- [확정] 말하는 상대(NPC) 3종:
  1. 동물 주민(햄스터, 이름: 바틀이): 섬에 사는 주민. 물고기를 사 주고 낚시 팁을 줘요. [확정] 햄스터, 소심하지만 다정한 성격 (조심스럽게 말하고 선물을 잘 줘요)
  2. 동물 친구: 갈매기(부두·바다 쪽)와 고양이(오두막 쪽) 두 마리. 말투가 귀여워요. [확정]
     - 갈매기 [확정, 사용자 승인 2026-10-12]: 이름 끼룩이. 호기심 많은 수다쟁이, 바다 소식을 자랑하듯 말해요. 부두 끝 난간 위에 앉아 있고, 다가가 E를 누르면 짧은 말(낚시 팁·시간대 힌트)을 해요. 사고팔기는 없어요.
     - 고양이 [확정, 사용자 승인 2026-10-12]: 이름 모카. 느긋하고 졸린 성격, 말끝을 늘이고 하품을 자주 해요. 오두막 앞 햇볕 드는 자리에 앉아 있고, 다가가 E를 누르면 짧은 말을 해요. 사고팔기는 없어요.
  3. 상인(사람): 털털한 뱃사람 아저씨. 큰 배를 타고 가끔 와서 물고기를 사 가요. [확정]
     - 상인 [확정, 사용자 승인 2026-10-12]: 이름 돌쇠. 호탕하고 털털해요("허허, 좋은 물고기구먼!"). 배 근처에 서 있고, 하루 중 노을 시간대에만 와요(낮·밤에는 사라짐). 바틀이처럼 3m 안에서 바라보고 E로 대화, 왼쪽 클릭으로 가진 물고기를 모두 파는데 값을 20% 더 쳐줘요(소수점은 반올림). 낚싯대 업그레이드는 바틀이만 해요.
- [확정] 1차 버전은 동물 주민 1명만 구현(판매 + 팁). 나머지 둘은 2차 이후. → 2차(사용자 승인 2026-10-12)에서 갈매기 끼룩이·고양이 모카·상인 돌쇠를 추가.
- [제안] 2차 NPC 구현: 임시 도형(동그란 몸·머리 등)으로 먼저 만들고 블렌더 모델 교체는 이후. 대화 방식은 바틀이와 같음(3m, 바라보기, E로 열기·닫기, 대화 중 시간 정지). 끼룩이·모카는 짧은 말 3개 중 하나를 무작위로, 돌쇠는 물고기가 있으면 판매 안내·없으면 안내 한마디.
- [확정] 판매(6-2) 방식 (사용자 승인 2026-10-12): 바틀이 3m 안에서 바라보고 E키로 대화창, 왼쪽 클릭으로 가진 물고기 모두 판매, E 또는 Esc로 닫기. 대화 중 게임 시간 정지.
- [제안] 가격(임시): 흔함 10원 / 보통 30원 / 희귀 100원. 소지금은 화면 하단 오른쪽에 "소지금 n원". 팔 물고기가 없으면 낚시 팁 3개 중 하나를 말함. 도감 기록(누적)과 보유 물고기 수는 별개. 바틀이는 임시 도형으로 오두막 옆에 배치. 선물 주기·저장은 이번에 안 함.
- [확정] 낚싯대 업그레이드 (사용자 승인 2026-10-12): 바틀이 대화창에서 번 돈으로 낚싯대를 키워요. 3단계(기본 → 튼튼한 낚싯대 → 반짝 낚싯대). 효과는 릴 감기의 내 칸(초록)이 넓어지는 것뿐, 희귀 확률·입질 시간은 그대로. 낚싯대 모양 바뀜·저장은 이번에 안 함.
- [제안] 업그레이드 수치(임시): 튼튼한 낚싯대 200원(내 칸 0.25 → 0.32), 반짝 낚싯대 600원(→ 0.40). 대화창에서 오른쪽 클릭으로 구매, 돈이 모자라거나 이미 최고면 안내 문구만. 현재 낚싯대 이름은 대화창에 표시.
- [확정] 상인이 오는 배가 맵의 "배" 모델링과 연결돼요.

## 4. 시점과 조작
- [확정] 1인칭 시점
- [확정] 이동: WASD, 시점: 마우스, 낚싯대 던지기/낚기: 마우스 왼쪽 클릭, 인벤토리/도감: Tab

## 5. 핵심 루프
`낚시 → 도감 등록 → 판매 → 장비 업그레이드 → 더 좋은 물고기`
- [확정] 도감 수집 + 판매/업그레이드 둘 다
- [확정] 1차 버전은 "낚기 → 도감 등록 → 판매"까지. 업그레이드는 2차.

## 6. 낚시 방식
[확정] 두 단계
1. 입질 타이밍: 찌가 가라앉는 순간에 맞춰 클릭해서 바늘을 걸어요.
2. 릴 감기: 물고기가 당기는 힘에 맞춰 버티며 감아요.

- [확정] 1차는 1단계(타이밍)만 구현하고, 2단계를 그 위에 붙여요.
- [확정] 릴 감기(2단계) 방식 (사용자 승인 2026-10-12): 입질 타이밍에 성공하면 화면에 가로 막대가 나타나요. 막대 위를 물고기 표시가 랜덤하게 움직이고, 내 칸은 왼쪽 버튼을 누르고 있으면 오른쪽, 떼면 왼쪽으로 움직여요. 물고기 표시가 내 칸 안에 있으면 아래 게이지가 차고, 벗어나면 줄어요. 가득 차면 낚기 성공(도감 등록·인벤토리 추가), 0이 되면 놓쳐요(아무것도 못 얻음). 흔함은 느리고 쉽고, 희귀는 빠르고 어려워요.
- [제안] 릴 감기 수치(임시): 막대 길이를 1로 볼 때 내 칸 너비 0.25, 내 칸 이동 속도 0.7/초, 게이지 시작 0.3 · 칸 안 +0.35/초 · 밖 −0.25/초, 물고기 표시 속도 흔함 0.35 / 보통 0.6 / 희귀 0.9 (0.6~1.2초마다 새 목표 지점으로 이동). 도감·대화 중에는 시간이 멈춰 릴 감기도 멈춤. 2단계 도중 다른 조작(다시 던지기 등)은 없음.

## 7. 시간과 물고기
- [확정] 실시간으로 낮 → 노을 → 밤이 바뀌어요.
- [확정] 시간대마다 잡히는 물고기가 달라요.
- [확정] 물고기 구성: 흔한 물고기는 실제 물고기(고등어, 도미, 복어 등), 희귀한 물고기는 상상 속 귀여운 물고기(구름·별 모양 등)
- [확정] 하루 길이: 현실 10분. 시간대 3종(낮/노을/밤), 물고기 종류는 1차에 6~8종.
- [확정] 1차 물고기 8종 (사용자 승인 2026-10-12). 구분은 흔함/보통/희귀.

| # | 이름 | 구분 | 잡히는 시간대 |
|---|---|---|---|
| 1 | 고등어 | 흔함 | 낮·노을·밤 |
| 2 | 도미 | 흔함 | 낮 |
| 3 | 가자미 | 흔함 | 낮·노을 |
| 4 | 복어 | 보통 | 노을 |
| 5 | 오징어 | 보통 | 밤 |
| 6 | 구름고기 | 희귀 | 낮 |
| 7 | 노을별고기 | 희귀 | 노을 |
| 8 | 별똥고기 | 희귀 | 밤 |

- [제안] 구분별 확률(임시): 흔함 70% / 보통 25% / 희귀 5%, 같은 구분 안에서는 균등.
- [확정] 시간대 길이(사용자 승인 2026-10-12): 하루 10분 = 낮 4분 → 노을 2분 → 밤 4분, 게임은 낮에 시작. 낚을 때 현재 시간대에 잡히는 물고기만 나옴(위 표). 시계는 도감·대화 중 멈춤.
- [확정] 그 시간대에 없는 구분의 확률은 흔함으로 합침(예: 낮은 보통이 없어서 흔함 95% / 희귀 5%). 흔함도 없는 경우는 없음(모든 시간대에 흔함 있음).
- [제안] 낚기 타이밍(임시): 찌가 뜬 뒤 입질까지 3~8초, 입질 후 1초 안에 클릭하면 성공.

## 8. 맵
- [확정] 작은 섬 하나로 시작. 나중에 낚시 포인트 확장.
- 구성: 섬, 야자수, 부두, 배, 낚시 오두막 (블렌더에서 모델링)
- [확정] 8단계 진행 방식(사용자 승인 2026-10-12): 블렌더 모델을 한 번에 하나씩(섬 → 부두 → 오두막 → 야자수 → 배) 임시 도형과 같은 크기·위치로 교체하고, 그때마다 검수와 사용자 확인을 받음. 임시 도형은 지우지 않고 비활성화(`_Temp`)해서 되돌릴 수 있게 둠.
- [확정] 바틀이 모델(8-6, 사용자 승인 2026-10-12): 동글동글한 햄스터(몸통·머리·볼·귀·눈·코·모은 앞발·발·꼬리), 키 약 1.3, 소심한 느낌으로 머리를 살짝 숙인 자세. 기존 위치 (-3,0,4)에서 섬 가운데를 바라봄. 대화·판매는 그대로. 말투·행동 애니메이션은 이번에 안 함.
- [확정] 동물 친구·상인 모델(8-7~9, 사용자 승인 2026-10-12): 임시 도형을 블렌더 모델로 교체. 순서 끼룩이 → 모카 → 돌쇠, 하나씩 만들고 검수·사용자 확인. 임시 도형은 `_Temp`로 비활성화해 보관. 같은 위치·방향, 대화·판매 그대로, 움직임 애니메이션은 안 함. 디자인: 끼룩이(키 약 0.7) 동글한 흰 몸통·회색 날개와 등·주황 부리와 발·까만 눈·고개를 갸웃한 자세 / 모카(키 약 0.6) 베이지 몸에 갈색 줄무늬와 귀·꼬리를 감고 앉은 졸린 자세·반쯤 감은 눈·분홍 코 / 돌쇠(키 약 1.9) 둥근 체형·파란 줄무늬 상의·갈색 바지와 장화·노란 모자·덥수룩한 수염·웃는 얼굴. 공통으로 로우폴리 단색 머티리얼.
- [제안] 파일 위치: 블렌더 작업 파일 `blender/`, 유니티용 모델 `Assets/Models/*.fbx`. 색은 단색 머티리얼 유지(텍스처 이미지는 이후 필요하면 추가). 섬은 모래 둘레 + 초록 풀 언덕 2색, 윗면 높이 0·반지름 20·두께 0.5.

## 9. UI
- [확정] 화면 중앙 작은 조준점, 입질 시 찌 위 느낌표, 하단에 현재 시간대와 소지금, Tab으로 도감.
- [제안] 릴 감기 화면: 화면 가운데 조금 아래에 가로 막대(물고기 표시=주황 칸, 내 칸=초록 칸)와 그 아래 게이지 막대. 임시 도형으로 만들고 예쁜 그림은 나중에.
- [제안] 도감(6-1): 화면 가운데 패널. 오른쪽 8칸 격자(못 잡은 칸은 검은 "???"), 칸 클릭 시 왼쪽에 이름·구분·잡은 수, 위쪽에 수집 현황 "n/8". 열려 있는 동안 게임 시간이 멈춤. Tab 또는 Esc로 닫음. 저장 없음.
- [확정] 물고기 그림(8단계, 사용자 요청 2026-10-12): 블렌더에서 만든 귀여운 로우폴리 8종을 투명 배경 그림(PNG)으로 렌더해 도감 칸과 큰 그림에 표시. 못 잡은 물고기는 같은 그림을 까맣게 칠한 실루엣 + "???". 그림 파일은 `Assets/Fish/Fish_01~08_*.png`(순서는 8종 표와 같음), 칸 4개 배치는 패널(폭 900) 안에 들어오게 정리. 물고기 3D 모델·낚았을 때 연출은 이번에 안 함.
- [제안] 물고기 디자인: 고등어(청록 등+줄무늬), 도미(분홍 빨강, 큰 눈), 가자미(위에서 본 납작한 모습, 눈 2개), 복어(노란 둥근 몸+가시), 오징어(분홍 몸+다리 8개), 구름고기(구름 모양 몸), 노을별고기(눈 달린 주황 별), 별똥고기(남색 몸+불꽃 꼬리·노란 별 반점).
