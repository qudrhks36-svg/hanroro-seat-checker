# 낚시 게임 기획서 (GDD) v0.2

> 이 문서가 모든 작업의 기준이에요. 문서에 없는 내용은 짐작해서 만들지 않고 먼저 질문해요.
> `[확정]`은 사용자가 정한 것이에요. 새로 제안한 내용은 `[제안]`으로 표시하고, 확인받으면 `[확정]`으로 바꿔요.

## 1. 한 줄 소개
[확정] 잔잔하고 귀여운 작은 섬에서, 1인칭으로 낚시하며 도감을 채우고 장비를 키우는 힐링 낚시 게임.

## 2. 분위기
- [확정] 잔잔한 힐링 + 아기자기하고 귀여운 느낌
- [확정] 따뜻한 노을빛, 밝고 동글동글한 로우폴리 그림체, 부드러운 파도·바람 소리
- 참고 이미지 [확정]: `docs/reference/` 참고. 분위기·맵은 mood_map_* 2장, 도감·UI는 ui_* 3장. 이미지별 메모는 `docs/reference/notes.md`.

## 3. 세계관
- [확정] 한적한 바다 위의 작은 섬. 플레이어는 낡은 낚시 오두막을 물려받아 지내요.
- [확정] 대사는 많지 않게, 동물의 숲 같은 느긋하고 따뜻한 말투로 가끔 등장해요.
- [확정] 대사는 짧은 말풍선/대화창 형식. 낚시 팁, 물고기 구매 같은 일상 대화 위주.
- [확정] 말하는 상대(NPC) 3종:
  1. 동물 주민(햄스터, 이름: 바틀이): 섬에 사는 주민. 물고기를 사 주고 낚시 팁을 줘요. [확정] 햄스터, 소심하지만 다정한 성격 (조심스럽게 말하고 선물을 잘 줘요)
  2. 동물 친구: 갈매기(부두·바다 쪽)와 고양이(오두막 쪽) 두 마리. 말투가 귀여워요. [확정]
  3. 상인(사람): 털털한 뱃사람 아저씨. 큰 배를 타고 가끔 와서 물고기를 사 가요. [확정]
- [확정] 1차 버전은 동물 주민 1명만 구현(판매 + 팁). 나머지 둘은 2차 이후.
- [확정] 상인이 오는 배가 맵의 "배" 모델링과 연결돼요.

## 4. 시점과 조작
- [확정] 1인칭 시점
- [확정] 이동: WASD, 시점: 마우스, 낚싯대 던지기/낚기: 마우스 왼쪽 클릭, 인벤토리/도감: Tab

## 5. 핵심 루프
`낚시 → 도감 등록 → 판매 → 장비 업그레이드 → 더 좋은 물고기`
- [확정] 도감 수집 + 판매/업그레이드 둘 다
- [확정] 1차 버전은 "낚기 → 도감 등록 → 판매"까지. 업그레이드는 2차.

## 6. 낚시 방식
[확정] 두 단계
1. 입질 타이밍: 찌가 가라앉는 순간에 맞춰 클릭해서 바늘을 걸어요.
2. 릴 감기: 물고기가 당기는 힘에 맞춰 버티며 감아요.

- [확정] 1차는 1단계(타이밍)만 구현하고, 2단계를 그 위에 붙여요.

## 7. 시간과 물고기
- [확정] 실시간으로 낮 → 노을 → 밤이 바뀌어요.
- [확정] 시간대마다 잡히는 물고기가 달라요.
- [확정] 물고기 구성: 흔한 물고기는 실제 물고기(고등어, 도미, 복어 등), 희귀한 물고기는 상상 속 귀여운 물고기(구름·별 모양 등)
- [확정] 하루 길이: 현실 10분. 시간대 3종(낮/노을/밤), 물고기 종류는 1차에 6~8종.

## 8. 맵
- [확정] 작은 섬 하나로 시작. 나중에 낚시 포인트 확장.
- 구성: 섬, 야자수, 부두, 배, 낚시 오두막 (블렌더에서 모델링)

## 9. UI
- [확정] 화면 중앙 작은 조준점, 입질 시 찌 위 느낌표, 하단에 현재 시간대와 소지금, Tab으로 도감.

## 10. 만들 순서 (각 단계 끝에 직접 플레이 → 피드백)
1. 임시 도형(큐브·평면)으로 섬 맵 구성
2. 걷기 (1인칭 이동)
3. 낚싯대 던지기
4. 미끼
5. 낚기 (타이밍 → 릴 감기)
6. 도감 + 판매
7. 낮과 밤, 시간대별 물고기
8. 블렌더 모델과 텍스처로 교체

## 11. 아직 정해야 할 것
- 갈매기·고양이·상인의 이름과 성격
- 물고기 목록과 시간대별 분포
- 타겟 플랫폼 (PC 가정)
