## 1. 한 줄 소개
[확정] 잔잔하고 귀여운 작은 섬에서, 1인칭으로 낚시하며 도감을 채우고 장비를 키우는 힐링 낚시 게임.

## 2. 분위기
- [확정] 잔잔한 힐링 + 아기자기하고 귀여운 느낌
- [확정] 따뜻한 노을빛, 밝고 동글동글한 로우폴리 그림체, 부드러운 파도·바람 소리
- [확정] 소리 (사용자 결정 2026-10-12): 코드로 만든 파도·바람 합성 소리는 "별로고 너무 크다"는 의견으로 **빼고 삭제**함(유료 AI 소리 생성은 쓰지 않음). 대신 사용자가 준 무료 음원 `monume-background-music-576955.mp3`(`Assets/Audio/Bgm_Monume.mp3`, 출처·이용 조건은 사용자가 확인한 무료 음원)을 **배경음악(BGM)** 으로 게임 내내(도감·대화 중에도) 반복 재생. 기본 볼륨은 작게(0.2, 사용자가 들어 보고 괜찮다고 확인). 효과음은 NPC가 말을 걸 때(대화창이 열릴 때)만 먼저 넣고, 소리 파일이 없으므로 코드로 만든 합성 소리로 시작(사용자 선택 "가"): 갈매기 끼룩이 울음소리를 먼저 만들어 들려 주고(노이즈 지적으로 잡음을 뺀 2번째 버전 승인), 이어 상인과 고양이 소리를 만듦. [확정, 사용자 승인 2026-10-12] 끼룩이="끼-룩 끼룩"(맑은 새소리), 모카="냐-냥-냐"(고양이 울음은 "너무 날카롭다"는 의견으로, 동물 흉내 대신 상인처럼 짧고 낮고 부드러운 NPC풍 소리 세 번), 돌쇠="허-허-허"(낮은 아저씨 목소리 세 번). 말 걸 때(E로 대화창이 열릴 때) 재생, 볼륨 0.5. (까마귀는 게임에 없어서 사용자 확인 대기), 볼륨 조절 화면은 안 함(필요하면 이후에 사용자와 정함). [확정, 사용자 요청 2026-10-13] BGM이 너무 신난다는 의견으로, 음원 전체가 아니라 **잔잔한 앞부분(0~16.5초)만 반복**. 드럼이 들어오는 "딩"(16.75초) 직전에서 처음으로 돌아가고, 이음새는 0.5초 동안 소리를 줄였다 키워 부드럽게(소리 분석으로 드럼 시작 시점 확인).
- [확정] M키 음소거 (사용자 선택 2026-10-12): M키를 누를 때마다 소리 전체(BGM·효과음·NPC 소리)를 끄고 켬. 게임 중 언제나(도감·대화 중에도) 동작.
- [확정, 사용자 선택 2026-10-14] 효과음 추가 3가지(코드로 만든 합성 소리, 유료 생성 안 씀): ① 찌가 물에 떨어질 때 "퐁"(물방울), ② 새 물고기가 도감에 등록될 때 "띠-링"(높고 맑은 두 음, 낚기 소리가 끝나갈 즈음 시작), ③ 오늘의 목표를 채울 때 팡파르(올라가는 네 음, 앞 소리들이 끝난 뒤 시작). 희귀 물고기 전용 소리는 도감 등록 소리와 겹쳐서 뺌. 볼륨은 기존 효과음과 같음(0.5).
- [확정] 음소거 표시·저장 (사용자 확인 2026-10-12 "굿"): 꺼져 있는 동안만 화면 오른쪽 아래에 작게 "소리 꺼짐 (M)"을 표시. 음소거 상태는 저장하지 않고 게임을 켤 때마다 소리가 켜진 채로 시작.
- [확정] 나머지 효과음 5종 추가 (사용자 요청 2026-10-12): 던지기·입질·낚기 성공·놓침·판매. 역시 코드로 만든 합성 소리(소리 파일이 생기면 바꿔 끼움), 볼륨 0.5, 위 NPC 소리와 같이 잡음 없이 맑고 짧고 부드럽게. 소리 모양은 [제안]: 던지기=가볍게 올라가는 "휙"(음높이가 쭉 올라갔다 내려옴), 입질=밝은 두 음 "띠링"(느낌표가 뜨는 순간), 낚기 성공=밝게 올라가는 네 음 "딩딩딩딩~", 놓침=낮게 내려가는 두 음 "뿌-웅", 판매=동전 "짤랑". 낚싯대 구매 소리는 이번에 안 함.
- 참고 이미지 [확정]: `docs/reference/` 참고. 분위기·맵은 mood_map_* 2장, 도감·UI는 ui_* 3장. 이미지별 메모는 `docs/reference/notes.md`.

## 3. 세계관
- [확정] 한적한 바다 위의 작은 섬. 플레이어는 낡은 낚시 오두막을 물려받아 지내요.
- [확정] 대사는 많지 않게, 동물의 숲 같은 느긋하고 따뜻한 말투로 가끔 등장해요.
- [확정] 대사는 짧은 말풍선/대화창 형식. 낚시 팁, 물고기 구매 같은 일상 대화 위주.
- [확정] 말하는 상대(NPC) 3종:
  1. 동물 주민(햄스터, 이름: 바틀이): 섬에 사는 주민. 물고기를 사 주고 낚시 팁을 줘요. [확정] 햄스터, 소심하지만 다정한 성격 (조심스럽게 말하고 선물을 잘 줘요)
  2. 동물 친구: 갈매기(부두·바다 쪽)와 고양이(오두막 쪽) 두 마리. 말투가 귀여워요. [확정]
     - 갈매기 [확정, 사용자 승인 2026-10-12]: 이름 끼룩이. 호기심 많은 수다쟁이, 바다 소식을 자랑하듯 말해요. 부두 끝 난간 위에 앉아 있고, 다가가 E를 누르면 짧은 말(낚시 팁·시간대 힌트)을 해요. 사고팔기는 없어요.
     - 고양이 [확정, 사용자 승인 2026-10-12]: 이름 모카. 느긋하고 졸린 성격, 말끝을 늘이고 하품을 자주 해요. 오두막 앞 햇볕 드는 자리에 앉아 있고, 다가가 E를 누르면 짧은 말을 해요. 사고팔기는 없어요.
  3. 상인(사람): 털털한 뱃사람 아저씨. 큰 배를 타고 가끔 와서 물고기를 사 가요. [확정]
     - 상인 [확정, 사용자 승인 2026-10-12]: 이름 돌쇠. 호탕하고 털털해요("허허, 좋은 물고기구먼!"). 배 근처에 서 있고, 하루 중 노을 시간대에만 와요(낮·밤에는 사라짐). 바틀이처럼 3m 안에서 바라보고 E로 대화, 왼쪽 클릭으로 가진 물고기를 모두 파는데 값을 20% 더 쳐줘요(소수점은 반올림). 낚싯대 업그레이드는 바틀이만 해요.
- [확정] 1차 버전은 동물 주민 1명만 구현(판매 + 팁). 나머지 둘은 2차 이후. → 2차(사용자 승인 2026-10-12)에서 갈매기 끼룩이·고양이 모카·상인 돌쇠를 추가.
- [제안] 2차 NPC 구현: 임시 도형(동그란 몸·머리 등)으로 먼저 만들고 블렌더 모델 교체는 이후. 대화 방식은 바틀이와 같음(3m, 바라보기, E로 열기·닫기, 대화 중 시간 정지). 끼룩이·모카는 짧은 말 3개 중 하나를 무작위로, 돌쇠는 물고기가 있으면 판매 안내·없으면 안내 한마디.
- [확정] 판매(6-2) 방식 (사용자 승인 2026-10-12): 바틀이 3m 안에서 바라보고 E키로 대화창, 왼쪽 클릭으로 가진 물고기 모두 판매, E 또는 Esc로 닫기. 대화 중 게임 시간 정지.
- [제안] 가격(임시): 흔함 10원 / 보통 30원 / 희귀 100원. [확정, 사용자 선택 2026-10-16] **먼 바다 물고기(13~16번)는 1.5배**(흔함 15 / 보통 45 / 희귀 150원) — 멀리 가는 보람. 도감·결과 카드의 "판매 값"도 같은 값을 보여 줌. 소지금은 상태창(9번)에 "n원". 팔 물고기가 없으면 낚시 팁 3개 중 하나를 말함. 도감 기록(누적)과 보유 물고기 수는 별개. 바틀이는 임시 도형으로 오두막 옆에 배치. 선물 주기는 이번에 안 함. (저장은 8번 이후 "저장" 항목으로 구현)
- [확정] 낚싯대 업그레이드 (사용자 승인 2026-10-12): 바틀이 대화창에서 번 돈으로 낚싯대를 키워요. 3단계(기본 → 튼튼한 낚싯대 → 반짝 낚싯대). 효과는 릴 감기의 내 칸(초록)이 넓어지는 것뿐, 희귀 확률·입질 시간은 그대로. 낚싯대 모양 바뀜은 이번에 안 함. (낚싯대 단계는 저장됨, 8번 "저장" 항목)
- [확정, 사용자 선택 2026-10-19 "NPC 대사·상호작용 추가 → 대사 늘리기 + 마음 쌓기 + 부탁(순서대로)"] NPC 확장 3단계. **① 상황별 대사(먼저 진행)**: NPC마다 대사를 8~10개로 늘리고, 시간대(낮·노을·밤)·날씨(맑음·흐림·비)·도감 진행(8종 이상, 다 채움)·낚싯대 최고 단계·소지금 500원 이상·대회 기록 유무에 맞는 대사를 우선(70%)해서 말함, 바로 앞에 한 말은 되도록 반복 안 함. 말투는 그대로(바틀이 소심한 말더듬, 끼룩이 "끼룩!", 모카 "~다냥…", 돌쇠 "허허"). 게임 사실과 맞지 않는 힌트는 쓰지 않음(물고기 시간대·미끼 성질은 표를 따름). 바틀이는 물고기를 들고 있으면 기존 인사·판매 흐름이 우선, 돌쇠도 판매 흐름 우선. 대사는 `data/dialog.json`(조건은 `when`). 구체 문구는 [제안]이라 플레이해 보고 고침. **② 마음 쌓기(친밀도)·③ 부탁(퀘스트)**: ①을 사용자가 플레이해 본 뒤 각각 따로 GDD에 정해서 진행(미정).
- [확정, 사용자 선택 2026-10-19 "물고기 선물 / 단계 보상은 새 대사 + 작은 선물"] **② 마음 쌓기(친밀도)**: NPC 4명(바틀이·끼룩이·모카·돌쇠) 각각 친밀도 점수(0~15)가 있고 ♥ 3단계. 대화창에서 **G** = 선물(물고기 1마리, 대화창에 "G 선물" 알약, 가진 물고기가 있고 아직 ♥3이 아닐 때만). 어떤 물고기를 줄지는 자동: 그 NPC가 좋아하는 물고기가 있으면 그것, 없으면 가장 싼 물고기. 좋아하는 물고기를 주면 +3점, 아니면 +1점. 선물한 물고기는 보유에서 빠짐(팔 수 없음). 단계 기준 [제안]: ♥1 = 3점, ♥2 = 8점, ♥3 = 15점. 단계가 오를 때 작은 선물 [제안]: ♥1 돈 30원, ♥2 도감 힌트(아직 못 잡은 물고기 하나의 시간대·장소를 알려 줌, 다 잡았으면 돈 50원), ♥3 돈 100원. 단계별 새 대사(`friend_min` 조건)와 선물 반응 대사(좋아하는 것/그냥/단계 오름)가 나옴. 좋아하는 물고기 [제안]: 바틀이 해마, 끼룩이 고등어, 모카 도미, 돌쇠 참치(처음엔 알려 주지 않고, 반응으로 알게 하고, ♥1 대사에 힌트). 화면: 대화창 오른쪽 위에 하트 3개(채워진 만큼). 저장: 친밀도 점수 4칸(`friend`), 옛 저장은 0.

## 6. 낚시 방식
[확정] 두 단계
1. 입질 타이밍: 찌가 가라앉는 순간에 맞춰 클릭해서 바늘을 걸어요.
2. 릴 감기: 물고기가 당기는 힘에 맞춰 버티며 감아요.
