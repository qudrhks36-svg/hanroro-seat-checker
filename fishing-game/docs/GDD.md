# 낚시 게임 기획서 (GDD) v0.1

> 이 문서가 모든 작업의 기준이에요. 문서에 없는 내용은 짐작해서 만들지 않고 먼저 질문해요.
> `[확정]`은 사용자가 정한 것, `[제안]`은 Claude가 제안해서 아직 확인이 필요한 것이에요.

## 1. 한 줄 소개
[확정] 잔잔하고 귀여운 작은 섬에서, 1인칭으로 낚시하며 도감을 채우고 장비를 키우는 힐링 낚시 게임.

## 2. 분위기
- [확정] 잔잔한 힐링 + 아기자기하고 귀여운 느낌
- [제안] 따뜻한 노을빛, 밝고 동글동글한 로우폴리 그림체, 부드러운 파도·바람 소리
- 참고 이미지: (사용자가 추가 예정 → `docs/reference/`)

## 3. 세계관
- [확정] 한적한 바다 위의 작은 섬. 플레이어는 낡은 낚시 오두막을 물려받아 지내요.
- [확정] 대사는 많지 않게, 동물의 숲 같은 느긋하고 따뜻한 말투로 가끔 등장해요.
- [제안] 대사는 짧은 말풍선/대화창 형식. 낚시 팁, 물고기 구매 같은 일상 대화 위주.
- [제안] 말하는 상대(NPC)는 아직 미정 → 섹션 11 참고.

## 4. 시점과 조작
- [확정] 1인칭 시점
- [제안] 이동: WASD, 시점: 마우스, 낚싯대 던지기/낚기: 마우스 왼쪽 클릭, 인벤토리/도감: Tab

## 5. 핵심 루프
`낚시 → 도감 등록 → 판매 → 장비 업그레이드 → 더 좋은 물고기`
- [확정] 도감 수집 + 판매/업그레이드 둘 다
- [제안] 1차 버전은 "낚기 → 도감 등록 → 판매"까지. 업그레이드는 2차.

## 6. 낚시 방식
[확정] 두 단계
1. 입질 타이밍: 찌가 가라앉는 순간에 맞춰 클릭해서 바늘을 걸어요.
2. 릴 감기: 물고기가 당기는 힘에 맞춰 버티며 감아요.

- [제안] 1차는 1단계(타이밍)만 구현하고, 2단계를 그 위에 붙여요.

## 7. 시간과 물고기
- [확정] 실시간으로 낮 → 노을 → 밤이 바뀌어요.
- [확정] 시간대마다 잡히는 물고기가 달라요.
- [제안] 하루 길이: 현실 10분. 시간대 3종(낮/노을/밤), 물고기 종류는 1차에 6~8종.

## 8. 맵
- [확정] 작은 섬 하나로 시작. 나중에 낚시 포인트 확장.
- 구성: 섬, 야자수, 부두, 배, 낚시 오두막 (블렌더에서 모델링)

## 9. UI
- [제안] 화면 중앙 작은 조준점, 입질 시 찌 위 느낌표, 하단에 현재 시간대와 소지금, Tab으로 도감.

## 10. 만들 순서 (각 단계 끝에 직접 플레이 → 피드백)
1. 임시 도형(큐브·평면)으로 섬 맵 구성
2. 걷기 (1인칭 이동)
3. 낚싯대 던지기
4. 미끼
5. 낚기 (타이밍 → 릴 감기)
6. 도감 + 판매
7. 낮과 밤, 시간대별 물고기
8. 블렌더 모델과 텍스처로 교체

## 11. 아직 정해야 할 것
- 대사를 하는 NPC (누구인지, 몇 명인지)
- 참고 이미지
- 물고기 목록과 시간대별 분포
- 타겟 플랫폼 (PC 가정)
