# 참고 이미지 가이드

이미지는 이 폴더에 넣고, 파일 이름은 `분류_설명.png` 형식으로 지어요. (예: `mood_sunset_dock.png`)

## 모을 분류와 장수 (총 8~12장이면 충분해요)
| 분류 | 장수 | 검색 키워드 |
|---|---|---|
| mood (분위기, 노을·바다 색감) | 2~3 | cozy island sunset, low poly sunset ocean, Animal Crossing island sunset |
| map (섬·부두·오두막 모양) | 2~3 | low poly island, wooden pier cartoon, fishing hut stylized |
| character (햄스터·갈매기·고양이 그림체) | 2~3 | cute hamster character 3d, stylized seagull, Animal Crossing villager |
| fish (물고기 모양) | 1~2 | cute low poly fish, stylized fish collection |
| ui (낚시 화면, 도감) | 1~2 | fishing game UI, Animal Crossing critterpedia, Stardew Valley fishing UI |

## 고르는 요령
- "이 느낌이다" 하는 것만 고르고, 장수를 늘리기보다 일관된 그림체로 맞춰요.
- 각 이미지마다 한 줄 메모를 `notes.md`에 남겨요. (예: "노을 색감만 참고, 건물은 X")
- 저작권이 있는 이미지는 개인 참고용으로만 쓰고, 게임에 그대로 넣지 않아요.
