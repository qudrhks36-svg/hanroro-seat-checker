# 참고 이미지 메모

저작권이 있는 이미지라 개인 참고용으로만 써요. 게임에 그대로 넣지 않아요.

## 분위기 · 맵
- `mood_map_cartoon_boat_hills.png`: 부드러운 초록 언덕과 하늘, 배 위에서 낚시하는 귀여운 동물. 상단 아이콘과 CATALOG 탭 배치도 참고.
  - 참고할 것: 색감(연한 초록, 하늘색), 동글동글한 형태, 잔잔한 분위기
- `mood_map_steam_festival_lake.png`: 호수 위 작은 배, 숲, 물속 물고기가 한 화면에 보이는 구도.
  - 참고할 것: 물 위/물속을 나눠 보여 주는 느낌, 숲과 물이 만나는 풍경

## 물고기 도감 · UI
- `ui_catalog_fish_book.png`: 책 모양 도감. 왼쪽에 큰 물고기 그림과 상세 정보(장소, 마릿수, 최고 기록), 오른쪽에 격자 목록. 못 잡은 물고기는 검은 실루엣.
  - 참고할 것: 도감 구성, 실루엣 처리, 수집 현황(6/49) 표시
- `ui_catalog_poki_collage.png`: 여러 캐주얼 낚시 게임 아이콘 모음.
  - 참고할 것: 캐릭터와 물고기의 단순하고 귀여운 표현
- `ui_fishing_tension_bar.png`: 물고기 체력(FISH HP)과 장력(TENSION) 바, 릴 감기 버튼.
  - 참고할 것: 릴 감기 단계의 게이지 구성. (그림체와 색은 참고하지 않음. 우리는 더 잔잔하고 귀여운 느낌)
