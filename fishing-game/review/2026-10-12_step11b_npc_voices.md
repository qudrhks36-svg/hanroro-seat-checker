## 항목별 결과

| 항목 | 결과 | 내용 |
|---|---|---|
| (1) GDD 일치 | 통과 | 끼룩이 "끼-룩 끼룩"(울음 3번, 시작 0/0.30/0.54초), 모카 "냐-냥-냐"(3번, 440~520Hz, 높은 소리 0, rolloff 1.1), 돌쇠 "허-허-허"(3번, 105~135Hz, 점점 작아짐). 재생은 E로 대화창이 열릴 때(`SetOpen(true)`), `voiceVolume` 기본 0.5(씬에도 0.5 저장). 모든 소리 Normalize 0.8, 잡음(랜덤 숨소리) 없음. |

| (4) 범위 밖 접근 | 통과 | 두 합성 함수 모두 `a + i < o.Length` 조건으로 배열 끝을 넘지 않음. 시작 위치는 0 이상. `Normalize`는 peak가 1e-6 이하면 나누기 자체를 건너뜀. |
| (4) 0 나누기 | 통과 | `t = i / (float)n`에서 n은 길이 0.15~0.30초 × 44100 = 6615 이상으로 항상 양수. `Normalize`는 위 조건으로 보호. |
| (4) 무한 루프 / f0 → 0 | 통과 | `for (h=1; h*f<9000; h++)`는 f가 양수일 때만 끝남. 실제 f 범위: 모카 약 413~546Hz(최저 440×0.94, 지터 ±1%), 돌쇠 약 약 90~136Hz(105×0.88, 지터 ±1%, 떨림 vibDepth 0). 최악의 경우도 약 100회 반복이라 안전. f가 0이나 음수가 되려면 `f0`가 0 이하이거나 지터가 -100% 이하여야 하는데, 지금 호출들은 모두 불가능. 다만 앞으로 `Voiced`를 새 값으로 호출할 때 f0 > 0, `jitter`는 1 미만이어야 함(코드에 안전장치는 없고, 현재 값에서만 안전). |

## 사소한 지적 (반려 사유 아님)

- `SfxSynth.cs` 4번째 줄 주석 "고양이·상인 소리는 아직 없음"은 이제 틀린 말(세 소리 모두 있음). 다음에 손댈 때 지우면 됨.
- `Voiced()`가 사실상 고정된 난수 시드(11)를 써서 세 음이 같은 흔들림을 가짐 — 의도된 재현성이라 문제 없음.

## 눈(귀)으로 못 본 부분

- 대화 때 실제 재생은 아직 확인 전(자동 시험은 파일 합성까지). 사용자 플레이로 확인 필요: 볼륨 0.5가 BGM(0.2)과 비교해 너무 크지 않은지, 돌쇠 노을에 나타났을 때 소리가 나는지, 시작 시 끊김이 없는지.
