# 검수: 11단계 c (낚시 효과음 5종)

- 날짜: 2026-10-12
- 검수 담당 (읽기 전용, 수정 없음)
- 기준: GDD 2번 "나머지 효과음 5종 [확정]" (소리 모양은 [제안]이지만 사용자가 파일로 듣고 "다 좋다"고 승인)
- 대상: `Sfx.cs`(새 파일), `SfxSynth.cs`(Cast/Bite/Catch/Miss/Sell, Bell, Soft), `FishingRod.cs`, `ShopNPC.cs`, `TalkNPC.cs`

## 항목별 결과

| 항목 | 결과 | 내용 |
|---|---|---|
| 던지기 | 통과 | `Cast()` 맨 끝(상태를 Flying으로 바꾼 뒤)에서 1회. Cast는 Idle에서 클릭할 때만 불려서 한 번에 한 번. |
| 입질 | 통과 | `StartBite()`에서만 1회. Floating에서 타이머가 끝날 때만 들어옴. |
| 낚기 성공 | 통과 | `Catch()`에서만 1회(게이지 가득 찼을 때). |
| 놓침 | 통과 | 두 곳 모두: 입질 시간 초과(Biting의 타이머 분기), 릴 감기 중 게이지 0(도망). 각각 한 번씩만. |
| 판매 | 통과 | ShopNPC(바틀이)·TalkNPC(돌쇠)의 `SellAll` 직후. 두 곳 모두 `TotalCount > 0` 조건 안이라 팔 물고기가 없으면 안 남. 바틀이의 우클릭(낚싯대 구매) 분기에는 소리 없음. 끼룩이·모카는 buyMultiplier 0이라 판매 분기 자체가 없음. |
| 중복 | 통과 | 육지에 던져 회수: Cast 소리만 나고 끝(Land의 육지 분기에 소리 없음, 사용자 의도에 맞음). 입질 전 클릭 회수: 소리 없음(GDD상 놓침이 아님). 입질 중 클릭(Hook)은 입질 소리 이미 났고 별도 소리 없음. 한 사건에 두 소리가 겹치는 경로 없음(Miss와 Catch는 서로 다른 분기, 같은 프레임에 둘 다 불리지 않음). |
| 누락 | 통과 | GDD가 요구한 5종 모두 연결됨. Hook(입질 성공 클릭)은 GDD에 소리 요구 없음. |
| Sfx.cs: 클립 재사용 | 통과 | 종류별로 처음 한 번만 만들어 딕셔너리에 저장, 이후 재사용. 소리 만드는 비용은 첫 재생 때 한 번(가장 긴 0.85초 = 약 3.7만 샘플, 문제 없음). |
| Sfx.cs: 재생기 | 통과 | AudioSource를 `DontDestroyOnLoad` 오브젝트에 만들고 2D(spatialBlend 0), playOnAwake 끔. 정적 필드는 `RuntimeInitializeOnLoadMethod(SubsystemRegistration)`의 `Reset()`이 Play 시작마다 비움(Domain Reload를 꺼도 죽은 AudioSource를 쥐고 있지 않음). `source == null` 검사도 Unity 객체의 파괴 상태를 잡아 줌. |
| timeScale 0 | 통과 | AudioSource는 timeScale의 영향을 받지 않음. `AudioListener.pause` 사용처도 없음(검색 확인). 판매는 대화창(timeScale 0) 안에서 나므로 이 점이 실제로 중요한데 문제 없음. |
| 볼륨 | 통과 | `Volume = 0.5f`를 PlayOneShot에 사용. GDD와 일치. |
| SfxSynth: 배열 범위 | 통과 | Bell·Soft 모두 루프 조건에 `a + i < o.Length` 포함(시작이 배열 밖이어도 안전). 각 소리의 끝 시각이 배열 길이 이내: 입질 0.45 ≤ 0.45, 성공 4번째 음 0.285+0.55=0.835 ≤ 0.85, 놓침 0.24+0.36=0.60 ≤ 0.62, 판매 0.085+0.28=0.365 ≤ 0.6. |
| SfxSynth: 0 나누기 | 통과 | `n`은 lenSec(상수 0.22~0.55초)×44100이라 항상 양수. 끝 페이드 `(n-i)/(0.02*Rate)`·`i/(0.004*Rate)` 분모는 상수. Cast의 `t = i / o.Length` 분모도 양수. Normalize는 peak ≤ 1e-6이면 건너뜀. |
| SfxSynth: NaN | 통과 | SmoothStep 입력은 루프 안에서 (n-i)>0이라 정상 범위, Exp(-decay·t)는 t 0~1이라 안전. 자동 시험에서도 5종 NaN 0. |
| 요청 밖 변경 | 통과 | 코드 변경은 요청한 곳(Sfx.cs 신규, SfxSynth 추가분, FishingRod 4줄, ShopNPC·TalkNPC 각 1줄)뿐. 기존 소리·저장·판매 로직 불변. 낚싯대 구매 소리는 안 넣어서 GDD와 일치. |
| 컴파일·소리 시험 | 통과 | 제출된 자동 시험상 오류 0, NaN 0, 시작·끝 0, 최고점 0.36~0.80. 사용자가 파일로 듣고 승인. |

## 참고 (반려 아님)

- 같은 소리가 연달아 나면 PlayOneShot이라 겹쳐서 울림. 판매는 클릭마다 팔 물고기가 있을 때만 나고, 팔고 나면 TotalCount가 0이라 연타해도 겹치지 않음.
- 게임 안 실제 재생 타이밍과 다섯 소리의 크기 균형은 코드 추적만으로 판단했고, 사용자 플레이로 확인 필요.
- 변경 파일(`Sfx.cs.meta` 포함)은 아직 커밋 전 상태. changelog 기록은 구현 담당 몫.
