# 검수: 1단계 임시 도형 섬 맵 (2026-10-12)

검수 담당 (만든 쪽과 다른 에이전트). 직접 고치지 않고 판단만 해요.
방법: Unity MCP로 SampleScene의 `Island`를 읽기 전용 조회 + 캡처 이미지 확인.

## 항목별 체크

| 항목 | 결과 | 확인한 내용 |
|---|---|---|
| 섬 + 바다 평면 | 통과 | `Ground` 납작한 원기둥(지름 40, 윗면 y=0), `Sea` 평면(200x200, y=-0.1) |
| 부두 | 통과 | `Pier` 직육면체 12x0.3x2.5, 섬 가장자리(x=18~30)에서 바다로 뻗음 |
| 오두막 | 통과 | `Cabin` > `Cabin_Body`(큐브) + `Cabin_Roof`(삼각기둥 메쉬 RoofPrism), 섬 안쪽 |
| 야자수 | 통과 | `PalmTree_01~04` 4그루, 각각 `Trunk`(원기둥) + `Leaves`(구), 모두 섬 안쪽 |
| 배 자리 | 통과 | `BoatSpot` 직육면체 6x1x2.5, 부두 옆 바다 위 |
| 알아보기 쉬운 이름 | 통과 | Sea, Ground, Pier, Cabin, PalmTree_NN, BoatSpot 등 |
| 모두 `Island` 아래 정리 | 통과 | 위 오브젝트 전부 `Island`의 자식 (Island 자체는 빈 오브젝트, 위치 0) |
| 단색 머티리얼만 | 통과 | Mat_* URP Lit, 텍스처 연결 없음 |
| 모델링/텍스처 금지 | 통과 | 기본 도형 + 삼각기둥 메쉬 하나(지붕용, 요구사항의 "지붕 삼각형")만 사용. 블렌더 모델/텍스처 없음 |
| 노을빛 참고 | 통과 | 지붕·배는 붉은 주황, 모래는 연한 살구색. 바다는 청록이라 노을 느낌은 약하지만 "참고" 수준이라 허용 |
| GDD 8번 구성(섬, 야자수, 부두, 배, 오두막) | 통과 | 5가지 모두 있음. 수치는 GDD에 없고 [제안] 임시값으로 밝혀져 있음 |
| 기존 `IslandMap_Temp` | 통과(참고) | 비활성화만 되어 있고 삭제 안 됨. 규칙 위반 아님 |

## 참고 (반려 사유 아님)
- 지름 40, 부두 12, 야자수 4그루, 배 1개는 [제안] 값이라 사용자가 플레이하며 확인해야 해요.
- 바다 색이 청록이라 노을 분위기는 7단계(시간대)에서 다시 다뤄질 듯해요.
