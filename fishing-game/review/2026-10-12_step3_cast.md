# 검수: 3단계 낚싯대 던지기

- 날짜: 2026-10-12
- 검수 담당 (읽기 전용, 수정 없음)
- 기준: GDD 4·6·9·10번 / 합의 범위(던지기+회수만, 왼쪽 클릭 한 번, 고정 12m, 임시 직육면체 낚싯대, 찌+줄, 조준점)

## 항목별 결과

| 항목 | 결과 | 내용 |
|---|---|---|
| 던지기/회수 동작 | 통과 | 대기 상태에서 클릭 = 던지기(0.8초 포물선), 물에 뜬 상태에서 클릭 = 회수. 날아가는 중 클릭은 무시. |
| 고정 거리 12m | 통과 | castDistance = 12, 수평 방향(카메라 정면의 수평 성분)으로만 던짐. 위·아래를 봐도 거리는 같고, 바로 위/아래면 몸 정면 사용. |
| 착지 판정 | 통과 | 착지점 위(y=20)에서 아래로 레이캐스트, 첫 충돌이 "Sea"면 물, 아니면 자동 회수. 기존 Ground(윗면 y=0, 반경 20)·Sea(y=-0.1)와 맞음. 섬 중심에서 8m 이상 바깥쪽(가장자리 20m 밖으로 착지)에서 던져야 물에 뜨는 설계와 일치. |
| 커서 재고정 클릭 누수 | 통과 | FishingRod는 실행 순서 -10으로 PlayerController보다 먼저 돌고, 던지기는 "커서가 이미 잠긴 상태의 클릭"만 인정. 재고정 클릭은 던지기로 안 샘. Esc로 해제된 상태의 클릭도 무시됨. |
| 범위 밖 기능 | 통과 | 입질·낚기·미끼·힘 모으기·물보라·소리 없음. 찌의 0.03m 흔들림(물 위 둥실)만 있는데 연출 수준이라 허용. |
| 씬 구성 | 통과 | Player에 FishingRod 연결: aimCamera=PlayerCamera, rodTip=RodTip, bobber=Bobber, line=FishingLine (4개 모두 연결). Rod는 PlayerCamera 아래 직육면체(Mat_Wood), RodTip은 Rod 자식. Bobber=구(Mat_Bobber), FishingLine=LineRenderer(폭 0.02, 월드좌표, Mat_Line), Crosshair=Overlay 캔버스 중앙 6x6 점. |
| 충돌 간섭 | 통과 | Rod·Bobber에 콜라이더 없음 (Player 이동과 레이캐스트 방해 없음). |
| 콘솔 | 통과 | 에러 0, 경고 0 |

## 참고 (반려 아님)

- 에디터 씬에서 Bobber·FishingLine이 켜진 채로 저장되어 있지만, 시작 시 `Start()`에서 꺼져서 플레이에는 영향 없음.
- 플레이 모드는 실행하지 않았어요(읽기 전용). 던졌을 때 모양·느낌은 사용자 플레이 피드백 필요.
