# 검수: 7단계 (낮과 밤, 시간대별 물고기)

- 날짜: 2026-10-12
- 검수 담당 (읽기 전용, 수정 없음)
- 기준: GDD 7번(시간대 표·길이·확률 합치기), 9번(하단 시간대 표시), 10번 7단계 / 합의 범위

## 항목별 결과

| 항목 | 결과 | 내용 |
|---|---|---|
| GDD 7번 표 대조 (Fish.cs) | 통과 | 고등어 낮·노을·밤 / 도미 낮 / 가자미 낮·노을 / 복어 노을 / 오징어 밤 / 구름고기 낮 / 노을별고기 노을 / 별똥고기 밤. 8종 모두 GDD와 일치. |
| ② 시간대 경계 | 통과 | 240초 미만 낮(4분), 360초 미만 노을(2분), 나머지 밤(4분, 600초까지). GDD 4/2/4분과 일치. 하루 600초, 끝나면 % 로 0으로 돌아감. |
| ① 보간 인덱스 | 통과 | 키프레임 7개(0,210,270,330,390,570,600). 반복문이 i를 최대 5까지만 올려서 Times[i+1]이 항상 존재. t=0 → i=0, t=570 이상 → i=5(570~600), t는 600 미만이라 범위 초과 없음. 구간 안 보간은 SmoothStep(부드러운 시작·끝). |
| ③ 시작과 이어짐 | 통과 | startClock=0(낮 시작). 570~600초에 밤→낮으로 보간되어 600(=0)에서 낮 값과 같아져 끊김 없이 이어짐. 노을 중간값(240초)에 라벨이 바뀌어 4/2/4분과 조명 전환 중심이 맞음. |
| 조명 보간 | 통과 | 방향 광 각도(55 → 6 → -25), 색, 밝기(2 → 1.6 → 0), 주변광 색을 같은 키프레임으로 함께 보간. 밤 밝기 0 + 남색 주변광(0.10, 0.13, 0.28)이라 완전 암흑은 아님. |
| ⑤ 시계 정지 | 통과 | 시계가 Time.deltaTime 기반이라 도감·대화 중(timeScale 0)에 멈춤. |
| ④ 물고기 풀 / 합치기 | 통과 | 시간대별 풀에 흔함이 항상 있음(낮: 고등어·도미·가자미 / 노을: 고등어·가자미 / 밤: 고등어). 비어 있는 구분(낮의 보통)은 확률을 흔함으로 합침 → 낮 95/0/5, 노을·밤 70/25/5. 구분 번호(Common=0, Uncommon=1, Rare=2)와 풀 인덱스 일치. 1만 번 표본 결과와 코드가 맞음. |
| FishingRod 연결 | 통과 | `FishTable.Pick(TimeOfDay.Current)` 한 줄 변경. 도감·판매 쪽 코드는 그대로. |
| 하단 시간대 표시 | 통과 | 하단 왼쪽 "낮/노을/밤" (28pt). |
| ⑥ 씬 저장 상태 | 통과 | Directional Light가 낮 값(각도 55, 색 1/0.97/0.92, 밝기 2)으로 저장. TimeOfDay 오브젝트에 sun=Directional Light 연결, dayLength 600, startClock 0. |
| 범위 밖 기능 | 통과 | 별·달·구름·파도·소리·미끼 효과·도감 시간대 표시 없음. |
| 콘솔 | 통과 | 에러 0. 경고 2건("Releasing render texture")은 에디터 화면 캡처 때 나온 것으로 게임 코드와 무관. |
