| 항목 | 결과 | 내용 |
|---|---|---|
| (1) Model 회전 | 통과 | `SampleScene.unity`의 PrefabInstance(&765759431, 부모 Seagull Transform 13840185)에서 Model 루트 `m_LocalRotation` = (x0, y0, z0, w1) = identity, 위치 (0,0,0), EulerHint (0,0,0). 이 인스턴스에서 바뀐 항목은 위치·회전·머티리얼 4개·이름뿐. |
| (2) 루트 방향 | 통과 | Seagull 루트 `m_LocalRotation` = (0, -0.7071, 0, 0.7071) = Y축 -90도. 로컬 +Z가 월드 (-1,0,0)이 됨. 부모 Island는 회전 identity, 위치 (0,0,0)이라 월드도 같음. 루트 (29.2, 0.3, 0)에서 섬 중심 (0, 0.3, 0)은 -X 방향이므로 일치. |
| (3) 측정값 타당성 | 통과 | FBX 규칙: 블렌더 앞(-Y) -> 유니티 로컬 +Z. 로컬 +Z가 월드 -X이므로 Model identity에서 부리(앞)는 루트보다 -X에 있어야 함. 측정 부리 x=28.72 = 29.2 - 0.48 (부리 길이만큼 -X). Y=180이면 +Z가 +X로 뒤집혀 29.2 + 0.49 = 29.69 (앞선 측정 29.69와 일치). 부리 y 0.80은 루트 0.3 + 머리 높이로 몸 높이 0.69와 맞고, z -0.04는 거의 0이라 정확히 -X 방향. 몸 중심 x는 앞선 검수의 꼬리 최소 x 28.76이 이제 반대쪽 끝이 될 것(꼬리 +X, 부리 -X)이라 모양도 일관됨. |
