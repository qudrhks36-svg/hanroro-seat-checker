## 눈으로 못 본 부분 (계산한 의견)

- 돌쇠 대화창은 패널 높이 260, 글자 상자 220, 글자 크기 26(줄 높이 약 35px). 물고기가 있을 때 줄이 7개(이름 / 빈 줄 / 말 / 빈 줄 / 물고기 목록 / 합계·클릭 안내 / 닫기) = 약 245px라서 상자 220을 넘어, 맨 아래 `[E / Esc] 닫기` 줄이 잘릴 수 있어요. 물고기 종류가 많아 목록이 줄바꿈되면 합계 줄까지 위험. E/Esc 동작 자체는 그대로라 기능상 막히진 않음. 바틀이 대화창은 9단계 b에서 같은 이유로 320/280으로 키웠으니, 잘리면 TalkNPC도 높이만 맞추면 돼요(피드백 대상). 끼룩이·모카는 4줄이라 안전.
- 실제 키/마우스 입력 시험은 못 함(에디터 포커스). 위 열림/닫힘 판단은 코드 흐름 추적 결과이고, 사용자 플레이로 확인 필요.
