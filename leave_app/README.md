# 연차 · 반차 결재

직원이 연차/반차 결재를 올리고, 대표가 승인/반려하면 남은 연차가 자동으로 계산되는 작은 웹앱.

## 규칙

| 항목 | 규칙 |
| --- | --- |
| 기준 | 입사일 기준 |
| 입사 1년 미만 | 개근한 달마다 1개씩 발생 (최대 11개) |
| 입사 1년부터 | 입사 기념일마다 15개 발생 |
| 이월 | 없음 — 기념일이 지나면 안 쓴 연차는 소멸 |
| 차감 | 연차 1일 = 1, 반차(오전/오후) = 0.5. 주말은 제외 |
| 잔여 | 발생 − 승인된 사용 − 승인 대기 중인 신청 |
| 취소 | 반려/취소하면 즉시 복구. 직원은 대기 건과 시작 전 승인 건을 취소할 수 있음 |

공휴일은 따로 빼지 않는다(공휴일에 연차를 올리지 않는다고 가정).
신청 한 건은 하나의 연차 기간(입사 기념일 ~ 다음 기념일 전날) 안에 있어야 한다.

## 로그인 방식

비밀번호 없이 **직원별 전용 링크**(`/?t=<긴 랜덤 토큰>`)로 접속한다. 대표 링크도 같은 방식이다.
- 테이블은 RLS 로 막혀 있어 anon 키로 직접 읽을 수 없고, 토큰을 검증하는 DB 함수(RPC)로만 접근한다.
- 링크가 유출되면 대표 화면 → 직원·잔여 → **링크 재발급**으로 기존 링크를 즉시 무효화한다.
- 접속 후 토큰은 브라우저에 저장되고 주소창에서는 지워진다.

## 설치

1. Supabase 프로젝트의 SQL 편집기(또는 마이그레이션)로 `supabase/schema.sql` 을 실행한다.
2. `supabase/seed.sql` 을 실행해 대표 계정을 만들고, 출력된 `token` 을 저장한다.
3. `.env.example` 을 `.env` 로 복사해 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 를 채운다.
4. `npm install && npm run dev`
5. 대표 링크 `http://localhost:5173/?t=<token>` 으로 접속 → 직원 추가 → 직원 링크 복사해서 전달.

배포는 Vercel 에서 이 폴더(`leave_app`)를 Root Directory 로 지정하고 위 두 환경변수를 넣으면 된다.

## 테스트

```bash
npm test                                   # 화면 보조 로직
psql -v ON_ERROR_STOP=1 -f supabase/test.sql   # 발생/차감/승인 규칙 (schema.sql 적용된 빈 DB에서, 끝나면 롤백)
```

`test.sql` 은 `anon`, `authenticated` 롤과 `extensions` 스키마(+pgcrypto)가 있는 DB를 가정한다(Supabase 기본값).
